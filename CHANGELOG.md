# Changelog

## 0.4.0-beta.1

First public preview of Flow Translate.

- Native macOS word lookup and region translation using local Vision OCR.
- Context limited to the pointed word's sentence, with wrapped-line support.
- Configurable DeepSeek / OpenAI-compatible Chat Completions and Apple Translation.
- Compact light/dark reading cards, streaming output, pronunciation, copy, save and pin.
- Local vocabulary, review scheduling, query history, and CSV / Anki / text export.
- Three-step first-run setup, Chinese/English UI, configurable gestures and shortcuts.
- Independent public app identity, user-provided Keychain credentials, no bundled account data.
- Source verification scripts, generated screenshots, installation/configuration/privacy documentation, and macOS CI.

Apple Silicon preview only. The app is ad-hoc signed and not Apple-notarized. See `docs/VALIDATION.md` for verified behavior and remaining limits.
